# Web Server

This project covers the basics of web servers, nginx, DNS and HTTP redirections.

## Files

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server using scp |
| `1-install_nginx_web_server` | Installs nginx and serves "Holberton School" on port 80 |
| `2-setup_a_domain_name` | Contains my .tech domain name |
| `3-redirection` | Configures a 301 redirect for `/redirect_me` |
| `4-not_found_page_404` | Configures a custom 404 page |
